# Tiinex Business

Tiinex Business is the organizational Workspace for Tiinex. It owns organizational intent, Project outcomes, Roles, reusable Business processes, financing provenance, and cross-Workspace disposition where those concerns genuinely belong here.

`.topics/**` is the semantic/provenance authority. This README is a human reception surface only: it explains what the repository is for, but it does not select current work or maintain an index of Tiinex artifacts.

## Durable boundaries

- Project is an outcome/work boundary, not a repository or grouping folder.
- Workspace is a technical/material ownership boundary and is independent of Project structure.
- Task and Task children are the ordinary executable decomposition.
- Cross-Workspace work preserves truthful declared ancestry and qualified recovery rather than creating parentless children for later repair.
- Business keeps organizational disposition concise and does not duplicate implementation state owned elsewhere.

## Working with this repository

Use Tiinex Tooling and the qualified Workspace material under `.topics` to discover current Projects, Tasks, Roles, Processes, Reductions, Decisions, and other authority relevant to the work at hand. README and `llms.txt` are deliberately not maintained as parallel indexes.

Historical execution may remain recoverable through immutable repository history and qualified Reductions without being presented here as current merely because old files or prose still exist.

## Human-facing use

This repository should remain understandable to a person browsing the source without requiring Tiinex internals, while currentness, ancestry, authority, acceptance, and work state remain derived from qualified Tiinex artifacts rather than README prose.
