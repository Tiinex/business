# The first public site asked for review

The **May 12** site revision is titled `Tiinex Feedback Spine`, not Lineage Viewer. Its HTML exposes areas for feedback, triage states, a current problem, human review and a human gate.

This matters because the project's outward-facing experiments originally included a way to receive, organize and present criticism, rather than only displaying finished technical claims.

- [May 12 Feedback Spine source HTML](https://github.com/Tiinex/site/blob/9f842301b04de6932f4799536ad59982fe412054/index.html).

## Boundaries

A static HTML frontend and its placeholders establish an **intended feedback interface**, not a count of outside participants, successful ingestion or moderation outcomes. It should not be presented as evidence that the current schema-aware viewer existed in this form already.
