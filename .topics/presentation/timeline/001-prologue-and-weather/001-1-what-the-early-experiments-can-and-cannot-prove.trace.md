# Before Tiinex had a name

The creator remembers trying ChatGPT Tasks and weather/radar assistance, then building a weather service when the available experience did not meet the practical need. This phase was **not yet a project to build an AI provenance framework**. There was also a break in AI-assisted development.

Another prehistory thread was an *Intrigue Map*: a role-playing interface concerned with characters, relationships and events. That work gave the developer useful prior experience for thinking about game state, but its exact version history has not been independently reconstructed for this presentation.

## Why this matters

If the beginning is told as a single inevitable invention story, it becomes less truthful. The historical question is: how did unrelated practical experiments become a new set of engineering questions? The safest answer is that the connection emerged later.

## Evidence boundary

- **Source:** the developer's October 2026 firsthand reconstruction and corrections.
- **Not independently established:** precise weather-service repository, release dates, implementation details or date of the Intrigue Map.
- **Do not infer:** that the weather system used current Tiinex schemas, or that every later feature descended directly from that work.

This intentionally stays within testimony until inspectable early project material can support stronger claims.
