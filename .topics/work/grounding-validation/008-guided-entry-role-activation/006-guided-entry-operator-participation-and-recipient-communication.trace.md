Selecting exactly one participant Role alone is insufficient evidence that the chat operator occupies it.

**Local correction:** Existing VS Code Guided Entry now asks an explicit optional operator-participation choice, including `None — context only`. It marks the exact selected participant with `operatorParticipant: true`, preserving that assertion through source-reference fallback and transport completion. Core qualifies the exact carried Role Assignment Modes before projecting the bounded `explicit-participation` instruction. Other selected participant Roles remain context; no permanent holder, Handoff routing, acceptance, Task authority or remote write follows. The semantic mode itself and Docs schema remain unchanged.
