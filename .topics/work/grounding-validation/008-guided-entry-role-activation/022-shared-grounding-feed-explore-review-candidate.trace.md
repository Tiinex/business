## Design incentives
- **Common grounded reality, differentiated use**: every ready Workspace carrier or qualifying Entry may use the same Tooling-projected baseline; Explore, Resume and formal Handoff may traverse different relevance paths without withholding baseline truth.
- **Broad then deep**: global chronology + per-Workspace coverage; `--focus` only when meaningful to source/Task/Return/ownership questions, without hardcoding depth or minimum read count.
- **No false narrative**: carrier snapshot validity is not semantic currentness; top-15 skew is explicitly visible, and filters/pagination do not erase other Workspace coverage.
- **Explore is not Execute**: present sourced reality, suggested direction and intended mutations; allow operator to object; retain separate actual authority qualification. A checkpoint is not a trigger to select a new Guided Entry.
- **CLI operations are state-free**: no truthful server-enforced approval gate can be claimed without authenticated qualified session context. Model-facing Entry guidance is useful but weaker than a hardened host boundary.
