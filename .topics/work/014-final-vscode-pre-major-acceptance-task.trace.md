# Final VS Code Pre-Major Acceptance

## Objective

Provide one bounded Sigma acceptance outcome for the final current-Major operator candidate before the explicit stable Major checkpoint.

The implementation frontier consists of:

- Task 012: five-mode Parent-backed Outgoing source presets;
- Task 013: dirty Replace Discard, Reset All Dirty Workspaces, Local/Latest linked-build shortcuts, and package-level Guided Entry for pointerless/routed carriers while preserving pointer-level Copy Transport Text.

This Task is acceptance-only and adds no third implementation scope.

## Acceptance Surface

1. Parent-backed Outgoing exposes the `Source preset` cycle in this order: Incoming only → None → Prefer Local → Prefer Incoming → Local only → Incoming only.
2. Dirty Incoming Replace exposes `Discard local changes` as the final dirty-resolution option.
3. `Tiinex: Reset All Dirty Workspaces` shows No active/default and Yes below it; Yes resets dirty Git Workspaces to committed HEAD while ignored files remain.
4. `Tiinex: Build linked extension` still exists and retains its existing linked-build mechanics. `Tiinex: Build linked extension (Local)` performs Switch all to Local before build and is the default test task. `Tiinex: Build linked extension (Latest)` performs Switch all to Latest before build and is the default build task.
5. Transport package rows expose `Guided Entry` for both pointerless Workspace carriers and routed Handoff carriers.
6. A routed package-level Guided Entry preserves the exact qualified Handoff Continue From route; if more than one route exists, route selection is required.
7. Individual Handoff Pointer rows still expose `Copy Transport Text`; routed package rows do not need a second raw-copy action.

## Scope

- Real-host acceptance of Task 012 Parent-backed source presets.
- Real-host acceptance of Task 013 dirty Replace, global Git reset, linked-build shortcuts, and package/pointer recipient actions.
- No new implementation beyond the already-authored Task 012 and Task 013 candidates.

## Dependencies

- [Finish Outgoing Parent Source Presets Before Stable Major](012-finish-outgoing-parent-source-presets-before-stable-major-task.trace.md)
- [Finish Dirty Workspace Controls, Build Shortcuts, And Package Guided Entry Before Stable Major](013-finish-dirty-workspace-controls-build-shortcuts-and-package-guided-entry-before-stable-major-task.trace.md)
- Current carried Core and VS Code Workspaces containing the candidate implementation.

## Done Criteria

- Sigma can exercise the seven user-visible acceptance points without debugging implementation.
- Any failing observation is returned to Anchor as a concrete blocker.
- If all acceptance points pass, this acceptance outcome is ready to support the explicit stable-Major checkpoint action; it does not itself perform or authorize that Major action.

## Boundaries

- No new carrier-lineage, Workspace identity, Replace/Initialize model, Package V1 topology, or Major-allocation rule is introduced by this acceptance Task.
- No remote mutation is authorized.
- Broader Core↔host/test-baseline audit work remains next-Major scope.
