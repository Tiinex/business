# Real-Host Sigma Gate Root-Cause Recovery

## Objective

Recover the current failed real-host Sigma gate by repairing the smallest correct Core and VS Code ownership seams in parallel, then prove the integrated product through the same real operator path without fixture/schema authority leakage, late avoidable Pack failures, or Workspace integrity drift.

## Done Criteria

- Reproduce and preserve all three gate failures as regression inputs: live endpoint contamination, Role-Handoff authoring-to-Pack closure mismatch, and Workspace-only integrity/conformance failure.
- Live endpoint candidates originate only from explicitly qualified Workspace/material authority. Nested `test/**/.topics`, schema examples, cached nearby Roles, repository-wide scans and human label recency cannot become live endpoint authority unless they are themselves the explicitly selected qualified Workspace/material source.
- Multiple exact candidates with the same human Role label remain distinct/ambiguous until qualified selection authority resolves them; the host must not silently collapse them by label.
- Shared Core endpoint projection consumes a bounded qualified source surface rather than treating every readable Role-shaped Markdown record supplied by a host as equally eligible production material.
- Supported Handoff authoring and Pack agree on endpoint/material requirements. Optional canonical endpoint References are not silently promoted into mandatory semantics; unresolved material remains unresolved at the exact allowed strength, explicit contradictions fail closed, and avoidable blockers surface at the earliest owning operation.
- Role/identity-unresolved Handoffs remain possible at the exact strength allowed by canonical Docs and are not rejected merely because no Role artifact can be materialized.
- Exact byte/integrity tracing establishes whether Incoming/Replace, Local dependency switching, Workspace authoring, or Pack preflight owns the observed Workspace self-integrity mismatch. Repair only the proven owner and add a deterministic regression covering the full transition.
- Host Outgoing/session state remains coherent across Topic/Handoff authoring and Attach actions; an existing Outgoing context cannot transiently disappear from one authoring surface without explicit state change.
- Participant behavior remains Core-qualified; add at least one positive multi-participant host case in integrated acceptance so the repaired product proves selection/presentation as well as the no-additional-participant case.
- Repository-owned machine acceptance reproduces the real production path and includes a negative assertion that repository test fixtures and schema examples cannot appear in live endpoint choices for a normal production Workspace.
- Local and Published Core host modes remain distinct and fail closed; no fallback or host-private semantic recreation is introduced.
- Loom and Kodax each return exact source delta, exact tests/receipts, residual risks and one qualified Handoff to Anchor. A lane that encounters authority outside its scope returns the blocker rather than patching around it.

## Scope

Parallel bounded recovery across Core shared Tooling and Extension VS Code host/controller/presentation mechanics, plus repository-owned regression/acceptance coverage required to reproduce the real Sigma gate.

## Dependencies

- Sigma Real-Host Gate Blocker Evidence.
- Current failed candidate Business/Core/Extension VS Code source.
- Canonical Docs Handoff/Role/Workspace schemas and validators, read-only.
- Existing Anchor architecture recovery decisions and accepted specialist audit results remain context, not automatic proof of current correctness.

## Boundaries

- No Docs semantic mutation without a returned exact contradiction and subsequent Axiom/Docs disposition.
- No broad monolith cleanup unrelated to the reproduced failures.
- No mandatory endpoint identity/reference invention merely to make Pack pass.
- No fixture deletion as a substitute for correct production discovery scoping; tests may remain repository-owned but must be semantically isolated from live production discovery.
- No label-based or repository-proximity inference of Role/Party authority.
- No Sigma debugging or implementation work.
- No remote mutation, release, publication or deployment.
