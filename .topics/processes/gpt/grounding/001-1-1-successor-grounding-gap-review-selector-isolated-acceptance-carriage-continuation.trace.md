# Successor Grounding Gap Review — Selector-Isolated Acceptance Carriage Continuation

## Purpose

Refine fresh-successor acceptance so strict isolation is enforced by qualified carrier scope rather than by asking the tested successor not to discover answer artifacts that are present in the same carried Workspace.

## Acceptance-Carriage Rule

- A successor probe that grades independent decision recovery must not carry completed answer/Evidence/Handoff artifacts from earlier runs when those artifacts are not required authority for the probe.
- When governing material and excluded answer material coexist in one source Workspace, use the canonical bounded Workspace Representation mechanism with an explicit exact entry set rather than carrying the complete Workspace and relying on operator search discipline.
- The bounded representation must include the Workspace artifact, controlling Task/Handoff, current Anchor Role, organization/root and the exact stable/current governing artifacts needed by the matrix.
- Parent/recovery closure required by selected included artifacts remains separately qualified detached recovery material and is not silently promoted into the bounded representation entry set.
- Omitted entries mean only `outside-representation`, never absent from the source Workspace and never deleted from recovery.
- The retained full recovery remains complete; bounded acceptance carriage is only the test/input surface.

## Isolation Gate

A run may count as strict-isolation evidence only when:

1. the carrier itself does not expose prior answer artifacts through its qualified Workspace representation;
2. cold grounding reaches the qualified organization root and the exact controlling frontier;
3. the successor answers the complete matrix from the governing material supplied;
4. no answer coaching or hidden prior-result material is introduced by the operator or runtime;
5. the returned Evidence records the representation boundary and any accidental external exposure.

If the test carrier itself contains the answer key, a correct response may still establish decision quality but cannot establish strict isolation.

## Defect Ownership

The failed clean replay demonstrated a Business Grounding/acceptance-harness composition defect, not an Anchor decision defect and not a missing Core capability. Current Core already supports explicit bounded Workspace Representation manufacture and detached Parent-boundary closure. Correct the process/carriage use first; change Tooling only if that qualified mechanism fails this use case.

## Interpretation Limits

This continuation does not redefine ordinary specialist carriage, complete Workspace semantics, Workspace identity, Parent semantics, or the main recovery frontier. It applies to isolation-sensitive successor acceptance and similar evaluation carriers where carrying prior answers would invalidate the gate.
