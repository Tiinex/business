# Core Participant, Preflight, And Carriage Inspectability Repair

## Objective

Implement only the reconciled Core corrections accepted by Anchor after independent Axiom, Loom, and Kodax audits: qualify current-work Task integrity before semantic participant derivation, fail earlier before expensive package construction when selected-route/current-work/material blockers are already known, and make detached textual carried material directly inspectable without promoting transport bytes into semantic authority.

## Done Criteria

- Semantic participant manufacturing derives declarations only from an exact current-work Task whose schema and c14n-v2 self-integrity qualify; stale/tampered/unqualified Task bytes produce no semantic participant requirement and one explicit blocking finding.
- Existing negative boundaries remain intact: manual participant input, Role/cache inventory, Handoff endpoints, package proximity, filenames, and host state do not create semantic participation.
- Blocking selected-Handoff/current-work/material preflight executes before tooling-bootstrap archive construction and recipient package assembly whenever the required facts are already available; a seam-level test proves blocked inputs do not enter expensive builders.
- Existing Required Context versus Reference Context behavior remains unchanged: unresolved/ambiguous/integrity-conflicted required material blocks; reference-only ambiguity does not become mandatory closure.
- Detached textual carried material is exposed with deterministic safe inspectable entry identity/media representation while exact bytes, digest, provenance, bounded scope, deduplication, and semantic non-authority remain unchanged.
- No automatic Party Capacity/Capacity Reference closure widening is introduced.
- No internal workspace/path binding becomes a durable semantic Reference.
- Focused adversarial regressions, existing participant/cache authority negatives, package roundtrip/orient/ground qualification, portable smoke, bootstrap qualification, and the full Core regression suite pass or any environment-limited evidence is reported without false PASS.
- Return one qualified Loom-to-Anchor Handoff carrying exact changed Core source, tests, and bounded evidence.

## Scope

Core portable Tooling participant-authority qualification, Handoff manufacture/preflight sequencing, detached material/cache presentation mechanics, and focused/full Core tests only.

## Dependencies

- Anchor Architecture Recovery Reconciliation Decision.
- Axiom Semantic Boundary Disposition — Handoff Endpoints, References, And Carried Material.
- Independent Core Material And Packing Audit — Loom Evidence.
- Current carried Core and Docs exact source snapshots.

## Boundaries

- No Docs schema mutation.
- No optional Handoff endpoint/kind change.
- No canonical resolver-state fields.
- No cache-to-Workspace-Representation semantic reclassification.
- No Party Capacity automatic closure requirement.
- No Extension VS Code mutation.
- No release, publication, deployment, or remote write.
- Do not broaden the fix into unrelated Core cleanup or architecture refactors.

## Acceptance Notes

Prefer the smallest correction at the semantic-authority source boundary and the smallest preflight extraction that proves failure timing. For inspectability, preserve current cache/External Payload authority boundaries; source-shaped entry names or an equivalent visible textual projection are acceptable only if they remain transport evidence and exact byte identity remains verifiable.
