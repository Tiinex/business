# Generate Bounded Visual Source Candidate

## Current Read

Ask the generative system for one bounded source candidate using visible-output language only: subject, composition, required variants or poses when applicable, material/style, count, and background/presentation constraints. The candidate may contain multiple related views when one atomic generation improves coherence.

The candidate is source material, not a runtime grid, final schema presentation, or deterministic export contract.

## Design Direction

Treat large design drift, missing required material, severe cutoffs, incoherent identity, or missing requested variants as candidate-level failure. Do not infer downstream semantic authority from generated labels, layout, or presentation residue.
