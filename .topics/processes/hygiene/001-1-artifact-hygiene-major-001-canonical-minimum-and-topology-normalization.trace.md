# Artifact Hygiene Major 001 — Canonical Minimum And Topology Normalization

## Objective
Turn the completed recursive 16-Workspace Hygiene audit into a bounded normalization plan that reduces grounding cost without mass-rewriting history or inventing new semantics.

## Scope
- Classify the current contract-critical artifact population against canonical minimum form: envelope, required sections/fields, footer/integrity method references, Parent representation, and schema locator representation.
- Separate current actionable breakage from valid historical representation and warning-only debt.
- Define safe normalization criteria for artifacts that are current or still attention-bearing.
- Classify numeric-directory topology such as `001/` buckets and sibling-Major patterns where continuation lineage may have been physically represented instead of encoded in artifact lineage.
- Classify repo-local supporting Markdown that duplicates Tiinex provenance/decision/human-gate responsibilities as possible shadow-documentation debt.
- Preserve provenance and historical recoverability; no mass deletion, bulk rename, or speculative rewrite.
- Route owner-specific implementation to Loom/Core or repository owners where Axiom does not own source mutation.

## Inputs
- Completed recursive 16-Workspace Hygiene audit return and findings.
- Current accepted Reduction 001 and Core 010 integrity behavior.
- Qualified Docs semantic contracts and Business grounding/process requirements.

## Dependencies
- Completed recursive 16-Workspace Hygiene audit evidence.
- Current accepted Reduction 001 and Core 010 lineage/integrity behavior.
- Canonical Docs schema/validator contracts and current Business process boundaries.

## Priority Order
1. Current contract-critical minimum-form errors.
2. Malformed or ambiguous Parent representation.
3. Integrity/schema-locator inconsistencies that affect qualification.
4. Major/continuation and numeric-directory topology classification.
5. Shadow Markdown classification.
6. Historical warning debt only after current surfaces are understood.

## Done Criteria
- Produce a qualified semantic classification that identifies which findings are current blockers, safe repair candidates, historical warnings, or owner-routed follow-ups.
- Define a small number of repair tranches rather than one test or rewrite per artifact.
- Explicitly state when numeric directory layout is semantically redundant or harmful and when lineage should instead be expressed in filenames/Parent metadata.
- Preserve the ability to commit WIP/RFC artifacts; hygiene qualification must not be conflated with ordinary Git commit policy.
- Return one qualified Tiinex Handoff package with exact next owner actions and no mass cleanup performed in this lane.
