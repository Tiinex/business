# Vision And Current Grounding

## Objective

Create a durable Tiinex Vision layer that explains why Tiinex is being built and the active architectural direction while preserving a strict boundary between current public identity, implemented capability, historical evidence, and future ambition.

## Done Criteria

- A cold human or LLM can distinguish: current identity; current implemented capability; active architectural direction; historical valuable insight; superseded assumption; ambition/unproven vision.
- Current organization/project identity remains grounded by the existing public statement that Tiinex keeps provenance readable in Markdown artifacts the user owns.
- The Vision layer does not redefine Docs schema authority, Site implementation status, Business Operations status, or Git history.
- Historical `ai`, `ai-vscode-tools`, older Site/Docs artifacts, screenshots, architecture diagrams, and other experiments are used as evidence only after classification/revalidation rather than as automatic current authority.
- Preserve the architectural direction `schemas/semantics -> shared Tooling/runtime capability -> multiple consumers`, with human and LLM surfaces consuming the same semantic truth where practical.
- Preserve schema-driven behavior, semantics/runtime/presentation separation, explicit relation/fallback behavior, portability, and recoverability while relaxing obsolete absolutes that would forbid generic runtime/tooling work for genuinely new capabilities.
- Produce a compact current-grounding surface that can feed `.github`, Docs, Site/Viewer, Operations, and future public materials without duplicating their authority.

## Discovery Sources

- Current Tiinex `.github` orientation/context and organization surface.
- Current Docs semantics/schema authority and relevant topics.
- Current Site refactor/reference implementation and its proven Viewer experience.
- Revalidated current `ai-provenance` capabilities only.
- Historical `ai`, `ai-vscode-tools`, prior architecture image(s), selected repository history, screenshots, and Business decisions as explicitly historical evidence.

## Scope

- Business-owned project Vision/current-grounding synthesis and classification.
- Source discovery across current public grounding and selected historical evidence.
- Does not redefine schema authority, implementation status, repository publication state, or Operations monitoring semantics.

## Dependencies

- Current Business organization, role, initiative, and operating artifacts.

- [Operating Overview And Monitoring](001-4-operating-overview-monitoring-task.trace.md)
