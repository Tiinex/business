# First Fresh Specialist Integration And Process-Discovery Hardening

## Objective

Integrate the first fresh Axiom/Loom returns and blind retrospectives, preserve only qualified semantic/Role/Tooling deltas, and coordinate the second bounded process-applicability/introspection fan-out before blind fresh-Anchor validation.

## Accepted First-Run Findings

- Fresh Axiom and fresh Loom independently preserved the boundary that `grounded-to-act` is selected-route action readiness rather than proof of organization-wide orchestration sufficiency.
- Carried Roles and Handoff endpoints remain grounding/transport facts unless qualified semantic authority establishes current-work relevance, participation, capability relationships, delegation or holder identity.
- Axiom found no need for a new Participant schema; current Party/Role + typed Relation + Handoff/Task/Decision/process authority is sufficient if applicability/relevance is actually carried and discoverable.
- Loom qualified additive Core mechanics that preserve complete/bounded/cache/unavailable source states, prevent Role carriage from becoming participation, separate orchestration readiness diagnostically, support exact-source blockers and accept a qualified pointerless Workspace carrier as Recovery byte basis without turning it into a Handoff.
- Loom's integrated Core source is accepted mechanically at this checkpoint after the controlling Anchor reran the complete Core test suite: 113/113 tests pass.
- Blind retrospectives exposed avoidable grounding cost in authority/readiness/participant explanation, provenance tracing, authoring enum/Parent guidance and manufacture preflight.

## Newly Confirmed Gap

Business already contains process artifacts, but fresh Roles do not receive a general authoritative projection of which processes apply unless applicability is encoded in the controlling Role/work lineage or otherwise explicitly related. The current system must not solve this by repository-wide process scanning or by making physical process presence equal applicability.

## Second Parallel Work

- **Axiom / Docs:** determine the canonical semantics for process applicability/discovery in sparse grounding. Prefer existing typed Relation and controlling Handoff/Task/Decision/process authority if sufficient; return the exact rule for how a fresh Role knows which process or processes apply without scanning everything or hardcoding every process in every Role.
- **Loom / Core:** harden introspection and authoring/preflight ergonomics already justified by the first run, while preserving semantic boundaries. Process-applicability projection may only be implemented when current authority already makes the relation explicit; otherwise return the exact semantic blocker for Axiom/Anchor reconciliation.
- **Anchor / Business:** retain organization/root lineage, integrate returns, decide any Business Role/process changes, build full recovery, and only then open the blind fresh-Anchor validation lane.

## Fresh-Role Diagnostic Discipline

For every newly spawned Role used to validate grounding, first execution is followed by a non-leading retrospective before corrections or a second assignment. Anchor compares received context, self-reported interpretation and observed behavior/output to classify Role, Handoff, process, Tooling, source-resolution or execution defects without contaminating the first-run model.

## Done Criteria

- Process applicability/discovery has a qualified semantic owner and a concrete cold-grounding rule that does not turn process inventory into authority.
- Core can expose enough explanation/provenance for a fresh Role to understand authority, source state, bounded action readiness and unresolved orchestration gaps without reading implementation internals.
- Authoring/manufacture failures relevant to first-run grounding provide actionable contract guidance where safe without weakening fail-closed behavior.
- Axiom and Loom second returns are reconciled against this same integrated Business/Docs/Core basis.
- A full recovery carrier is manufactured and rematerialized/audited before blind fresh-Anchor validation.
