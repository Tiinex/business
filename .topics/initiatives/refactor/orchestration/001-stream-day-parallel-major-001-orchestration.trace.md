# Stream-Day Parallel Major 001 Orchestration

## Objective

Run four bounded carrier Major 001 lanes in parallel without conflating carrier progression with artifact filename lineage: Anchor recovery/grounding hardening, VS Code operator trust/ergonomics, Viewer PoC replacement re-baseline, and Verse Playthings refactor reality testing.

## Done Criteria

- Anchor works local-first from one audited sixteen-Workspace full recovery carrier and treats `/mnt/data` materializations as disposable caches rather than continuity authority.
- Every incoming Handoff package is audited before merge; qualified deltas are merged into the current frontier instead of wholesale replacement, and a refreshed full recovery is emitted after meaningful accepted deltas.
- VS Code remains a semi-independent Sigma/Kodax lane; shared semantic or cross-repository blockers return to Anchor rather than expanding extension authority.
- Viewer re-baseline accounts for retained PoC product value using local carried evidence first, classifying discovered capabilities as KEEP, CHANGED INTENTIONALLY, DROP WITH REASON, or UNKNOWN before retirement claims.
- Verse Playthings is technically qualified on the refactored source set and real browser host path before Sigma human experience acceptance is requested.
- Chrome semi-automation remains queued until an active lane frees; no aggressive polling, host bypass, or remote mutation is inferred.
- Glimmer remains an audience-facing explanatory lane: qualified fact, plan, observation, unknown and acceptance are kept distinct.

## Scope

Coordination, recovery discipline, bounded delegation and reconciliation across the current Refactor frontier. Carrier Major numbers are local progress projections per carrier series and have no 1:1 relationship to artifact filename lineage or artifact Parentage.

## Safety Invariants

- Full Recovery Carrier is the continuity checkpoint; local extracted files are caches.
- Local carried source is preferred before remote lookup when it can answer the question.
- Remote lookup is explicit and evidence-driven; remote mutation/release requires separate authority.
- New findings do not silently expand a Major. Trade scope explicitly or defer to the next carrier Major.
- Schema and lineage semantics remain human-first and runtime-agnostic; runtime projections do not become hidden semantic authority.

## Human Gates

Sigma retains human experience acceptance, remote landing/release approval, and any decision to retire the historical Viewer PoC.

## Dependencies

- Current Refactor Turn-2 repository-frontier task and its qualified full recovery carrier.
- Sigma-approved stream-day plan and human gates.
- Current carried Workspaces for Business, Docs, Core, App, Site, extension-vscode, extension-chrome and Verse Playthings, with the remaining sibling Workspaces preserved in full recovery.
- Existing bounded specialist Roles and Handoff semantics; no new semantic authority is created by this coordination artifact.
