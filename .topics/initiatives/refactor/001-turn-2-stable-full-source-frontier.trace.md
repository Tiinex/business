# Turn 2 Stable Full-Source Frontier

This epic keeps the current Refactor turn legible across repository-owned work without turning Business into an implementation workspace.

## Current Read

The Refactor Anchor owns one reconciled multi-workspace frontier. Repository implementation work is decomposed into repo-local Tasks and Subtasks that point back to this controlling Business epic or its governing Turn-2 lineage.

## Design Direction

Stabilize source identity, provider-neutral Core/App boundaries, VS Code integration, Playthings host integration, Viewer capability, Site deployment/reduction, and operating Tooling while keeping semantic authority and implementation ownership separate.

## Next Artifacts

- Repo-local Tasks/Subtasks in Core, App, Docs, Site, VS Code and Playthings.
- Provider repository Tasks after Sigma supplies their current full-source Workspaces.
- Qualification Evidence and Handoffs returned through each repository's own lineage.
