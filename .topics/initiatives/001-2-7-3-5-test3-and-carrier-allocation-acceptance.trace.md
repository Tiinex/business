## Carrier Allocation Acceptance

- Loom's returned Core implementation derives ordinary non-Major allocation from exact qualified selected Handoff Pointer topology when deterministic.
- A single selected parent Pointer derives ordinary continuation suffix `-1` without recipient prose or manual sibling reservation.

- Each returned branch continues by appending its own `-1`; different prefixes allocate independently.
- Explicit manual sibling override remains only as a compatibility/advanced path and must match deterministic topology when topology already proves the value.
