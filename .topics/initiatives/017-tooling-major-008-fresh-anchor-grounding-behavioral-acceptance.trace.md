## Objective

Run the independent fresh-Anchor behavioral acceptance for direct Handoff Package V1 from an empty multi-workspace environment, using only the package-declared Start/bootstrap/Tooling path and qualified durable material. - The fresh Anchor reads the exact qualified Required Context/current-work bodies needed for substantive interpretation rather than treating machine qualification as proof that the body text has been read.
